# Database Design & Data Dictionary

Thư mục tài liệu cơ sở dữ liệu:
- `erd.md`: Sơ đồ quan hệ thực thể (ERD) chi tiết.
- `data-dictionary.md`: Từ điển dữ liệu mô tả các bảng, cột, kiểu dữ liệu, ràng buộc check, unique và nullability.
- `migration-guide.md`: Quy trình tạo và thực thi migration trên Microsoft SQL Server.
