# API Specification & OpenAPI

Tài liệu đặc tả REST API:
- `openapi.yaml` / `swagger.json`: Đặc tả theo chuẩn OpenAPI 3.0.
- `api-conventions.md`: Quy chuẩn đặt tên endpoint, format response, xử lý lỗi (400, 401, 403, 404, 409 Conflict, 500).
- `auth-flow.md`: Quy trình cấp phát Access Token, Refresh Token qua Cookie HttpOnly.
