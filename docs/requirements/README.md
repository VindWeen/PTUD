# Requirements & Business Rules

Thư mục chứa các tài liệu phân tích yêu cầu nghiệp vụ của hệ thống Quản lý Hồ sơ Thành tích:
- `SRS.md`: Đặc tả yêu cầu phần mềm.
- `business-rules.md`: Quy tắc nghiệp vụ chuyển trạng thái, khóa dữ liệu, minh chứng bất biến.
- `role-matrix.md`: Ma trận phân quyền theo vai trò (Lecturer, UnitRepresentative, Manager, RecordsOfficer, Admin) và phạm vi đơn vị.
